### 🚀 Sobre mim

Construo sistemas de ponta a ponta: do front-end ao back-end, da infraestrutura em nuvem à automação.
Gosto de resolver problemas reais com **APIs bem desenhadas**, **robôs que trabalham sozinhos**,
**integrações entre sistemas** e **IA rodando de verdade**, inclusive localmente.

- 🧠 IA local com LLMs, voz e reconhecimento de fala
- 🔌 APIs REST, microsserviços e contratos OpenAPI
- 🤖 Robôs e automações com n8n, webhooks e filas
- ☁️ Serverless na AWS (Lambda, API Gateway, DynamoDB, Cognito, Terraform)
- 🐳 Tudo empacotado em Docker
